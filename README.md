# On9 Autoplay

A lightweight Telegram userbot that automatically plays on9wordchain. It connects through your Telegram account, detects your turns across group chats, and replies with a valid unused word after a short, natural delay.

## Features

- Works across multiple group chats
- Keeps used-word history separate for each game
- Supports On9 Word Chain game constraints
- Runs continuously without a web server
- Can be controlled through Telegram Saved Messages
- Saves live preferences between restarts

## Requirements

- Node.js 18 or newer
- Telegram API credentials from [my.telegram.org](https://my.telegram.org)
- Your Telegram numeric user ID

## Setup

Clone the repository and install dependencies:

```bash
git clone git@github.com:mudgalz/on9-autoplay.git
cd on9-autoplay
npm ci
```

Create a `.env` file from the example:

```bash
cp .env.example .env
```

Open `.env` in a text editor. First, add the `API_ID` and `API_HASH` from the **API Development Tools** page at [my.telegram.org](https://my.telegram.org):

```env
API_ID=your_api_id
API_HASH=your_api_hash
```

Now run the login command:

```bash
npm run login
```

Enter your phone number with its country code, the login code sent by Telegram, and your two-step verification password if you use one. After a successful login, the command prints a long session string.

Copy the entire string and paste it after `SESSION_STRING=` in `.env`. Do not add spaces or quotation marks:

```env
SESSION_STRING=your_full_session_string_here
```

Finally, add your numeric Telegram user ID. You can get it by messaging `@userinfobot` or `@RawDataBot` on Telegram:

```env
MY_USER_ID=123456789
```

Your completed `.env` should contain all four values:

```env
API_ID=123456
API_HASH=your_api_hash
SESSION_STRING=your_full_session_string
MY_USER_ID=123456789
```

Keep this file private. Anyone with the session string may be able to access your Telegram session.

## Run the bot

Build the local word index and start the bot:

```bash
npm run prepare-words
npm start
```

`words.json` is generated by `prepare-words`. `settings.json` is created automatically when a live setting is changed. Both files are ignored by Git.

## Live controls

Send these commands to your own Telegram Saved Messages chat:

```text
.endletter y       Prefer words ending in Y
.endletter random  Return to random word selection
.stop              Pause automatic replies
.start             Resume automatic replies
```

Changes take effect immediately and are saved to `settings.json`.
